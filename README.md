# 血碗2 中文化补丁（Blood Bowl 2 Chinese Localization）

非官方《血碗2》(Blood Bowl 2) 简体中文汉化补丁。**不需要修改任何游戏本体文件结构**——游戏资源包(CPK)完全不动，以"松散文件覆盖"方式加载，随时可一键还原英文原版。

- 覆盖范围：界面、菜单、技能、规则、种族介绍、战役剧情、解说字幕、成就、商店、联赛系统、队名/球场名生成器等 **约 8,500 条文本**
- 保留英文：球员随机姓名（保留战锤风味原名）、纯符号/网址
- 术语依据《千锤百炼——血碗综合指南》《血碗队伍+技能资料》等中文资料集校订（附[中英对照词表](docs/血碗2中英对照词表.md)）
- 语音解说仍为英语（原版无中文语音）

## 适配版本

✅ **Steam 版最终版本 v3.0.219.2**（2024年后官方停更，此为最终版，可完全适配）

> 其他版本（GOG、Epic、非Steam渠道）**大概率可用**但未逐一验证；旧版本或文件结构不同导致安装失败时，见下方「AI 一行指令适配」。

## 🚀 安装（三步完成，无需任何代码操作）

**第 1 步**：下载本仓库（绿色按钮 `Code` → `Download ZIP`），解压得到 `BB2ChineseMod` 文件夹。

**第 2 步**：把整个 `BB2ChineseMod` 文件夹复制到血碗2游戏根目录——即 `BloodBowl2.exe` 所在的文件夹。

> 不知道游戏装在哪？打开 Steam → 库 → 右键《Blood Bowl 2》→ 管理 → 浏览本地文件，打开的就是游戏根目录。

**第 3 步**：双击 `BB2ChineseMod\install.bat`，看到"安装完成"即可。

启动游戏（语言设置保持 **English** 不用改），主菜单即为中文。✅

> 安装器会自动完成：备份原始英文语言库 → 部署中文文本 → 部署内置开源中文字体（文泉驿微米黑）。
> 想换成自己喜欢的字体？把任意中文字体文件（.ttf）改名为 `ChineseFont.ttf`，放到 `BB2ChineseMod` 文件夹里重新运行 `install.bat` 即可。

## 🔄 卸载 / 恢复英文

双击 `BB2ChineseMod\uninstall.bat`——自动还原原始英文语言库并清理所有补丁文件。

## ❓ 常见问题

**Q：安装后文字是空白？**
A：字体未正确部署。重新运行 `install.bat`；确认杀毒软件没有拦截 `Data\Gui\Fonts\` 下的 `.TTF` 文件。

**Q：游戏更新了怎么办？**
A：血碗2官方已停更（v3.0.219.2 为最终版），正常情况不会再有更新。若确实发生了更新且汉化失效，用上面的「AI 一行指令」重新适配。

**Q：部分球员名字还是英文？**
A：正常现象。随机姓名生成器保留英文原文名（战锤世界观人名），便于对照官方资料。

**Q：会影响联机/成就吗？**
A：本补丁只替换本地显示文本与字体，不修改任何游戏逻辑与服务器数据。但任何第三方补丁都无法保证在官方服务器上的表现，介意者请谨慎使用或仅离线使用。

**Q：想微调某个译名？**
A：参考 [docs/血碗2中英对照词表.md](docs/血碗2中英对照词表.md)；批量修改需重新打包语言库（可求助 AI 工具）。

## 🔧 工作原理（给技术向用户）

1. **语言文本**：游戏的本地化文本位于 `Data\DBToolDB\Localization\Default_loc_English.db`（Cyanide DSMGR 私有二进制格式）。本补丁按原格式重建该文件，将 11,368 条文本中的约 8,500 条替换为中文，其余保留原文；文中的 `$KEY` 内嵌引用已递归烘焙为最终文字。
2. **字体渲染**：游戏 GUI 基于 CEGUI/FreeType 动态渲染。将开源中文字体重命名覆盖为游戏引用的 9 个字体文件（放于 `Data\Gui\Fonts\`，引擎优先读取松散文件而非 CPK 包），即可显示中文。
3. **字形范围**：`Data\Gui\Fonts\fonts.xml` 声明了中文字符的 Unicode 范围供引擎预渲染。
4. 游戏 CPK 资源包**零修改**；唯一被替换的原始文件（英文语言库）会在安装时自动备份。
